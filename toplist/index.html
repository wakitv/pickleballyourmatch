How this list is kept honest

What the badge check does and does not prove
The spreadsheet is the record

A badge counts as official when it appears on this page. Every badge here was written to the organiser's Google Sheet when the session ended, and only someone who holds both that sheet and its secret phrase can add to it.

Each badge is fingerprinted

Every badge row carries a SHA-256 hash of the badge's own payload, and this page recomputes it rather than believing it. Edit a name, a rank or a record in the spreadsheet and that row is called out, so a quiet change does not go unnoticed.

A badge carries a checksum

Scanning a badge checks the result printed on it against a checksum baked into the QR, so an edited badge is rejected on sight — even before this list is consulted.

What it is not

PickleMatch runs entirely in your browser with no server, so a badge cannot be cryptographically signed: any key sent to a browser is public. A badge that passes its checksum but is missing from this list is unverified, not official.
